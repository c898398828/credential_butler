# 凭据管家 · 多站点自动填充 2.0

## 目标与范围

将财资云单站点助手扩展为按网站管理多组账号的 Chrome 插件。每个网站可选一个默认账号，打开其登录页时自动填写；临时选择其他账号用于手动填写，不修改默认身份。

界面结构参考用户提供的 VaultPulse HTML 的账号卡片和固定底部按钮，配色已改为克制的毛玻璃主题（见下节）。附件仅作为视觉参考，其中的演示数据、安全宣传、模拟器和源码不作为用户配置或实现要求。

## 界面与操作

约 400px × 580px 的中文弹窗，采用克制的毛玻璃风格：底层为单一冷蓝色系的深蓝灰渐变，叠加两三个低透明度的蓝色光斑和几颗淡淡的透明气泡（`popup.html` 中的 `.ambient` 装饰层，`aria-hidden`）；页头、页脚、账号卡片、工具卡片、菜单、对话框和状态栏为半透明白色玻璃面板（`backdrop-filter: blur() saturate()`、发丝描边与顶部高光）；主按钮、选中卡片、激活筛选和总开关使用天蓝→蓝的单色相渐变，强调色是界面上唯一的饱和颜色，绿/琥珀/红仅作状态语义且均降饱和。使用本地系统字体，账号信息以安全 DOM / `textContent` 呈现。

动效只使用 `transform` 与 `opacity`：视图切换时各玻璃面板依次升入，账号列表在数据变化（而非搜索输入）时错落入场，卡片悬停抬升、按钮光泽扫过、开关滑动、页头在 `aria-busy` 期间显示流光；`prefers-reduced-motion` 下全部关闭。注意 Chrome 在祖先元素有进行中的 transform/opacity 动画时会停止为后代采样 `backdrop-filter` 背景，因此入场动画只放在玻璃面板自身，输入框、次要按钮等位于动画容器内的小控件改用带高光的半透明填充而不做背景采样。

- 首页：当前网站状态、搜索、当前网站/全部账号筛选、账号列表、新增入口、自动填写总开关、固定底部填写按钮。
- 编辑页：名称、登录页地址、可选的企业编号、账号、默认遮蔽的密码、此网站默认账号选项。高级字段选择器折叠收纳。
- 账号菜单：编辑、设为默认、复制企业编号/账号/密码、删除；复制仅在用户点击时写入剪贴板。
- 工具页：密码生成、口令加密备份、合并导入、清空账号。清空要求确认并关闭自动填写。
- 删除默认账号或取消其默认状态后，不自动改用其他账号。未指定默认账号的网站保持不自动填写。

## 结构与存储

原生 JavaScript、Manifest V3，无构建、外部依赖、远程账号服务或后台 Service Worker。

| 文件 | 职责 |
| --- | --- |
| `common.js` | 数据规范化、校验、网站及登录页匹配 |
| `vault.js` | 读写、迁移、默认账号管理、密码生成与备份 |
| `sites.js` | 逐站点权限、动态内容脚本注册、手动填写调度 |
| `content.js` | 表单识别、财资云适配、输入与异步状态保护 |
| `popup.html` / `.css` / `.js` | 账号、编辑、工具界面 |

`chrome.storage.local` 的 `accountVault` 存储版本 2 数据：`profiles`、按 origin 索引的 `defaultProfiles`、全局 `enabled`。`defaultProfileId` 仅作为旧财资云数据的兼容别名。

账号字段包括 `id`、`name`、`loginUrl`、`enterpriseId`、`username`、`password`、三项可选 `selectors`、`createdAt`、`updatedAt`。同一 origin、企业编号、账号组合不能重复。最多 500 条账号；名称最多 40 字符，普通网站企业编号最多 128 字符，单个选择器最多 256 字符。财资云企业编号必填且最多 8 位。保存密码保留原值，不自动裁剪。

从旧 `defaultProfile` 迁移时，先成功写入新格式，再清理旧键；保留密码和自动填写开关，并将旧账号设为财资云默认账号。内容脚本在首次打开新版弹窗前也能读取旧配置继续工作。已存在的新数据始终优先，包括空账号库；损坏或不支持的数据不被静默覆盖。

修改前读取最新状态，写操作串行执行，并在浏览器支持时使用 Web Locks 协调多个扩展窗口。原目录重新加载扩展可沿用存储；卸载扩展或改变加载目录可能导致数据丢失或无法沿用。

## 网站匹配与权限

网站身份采用 URL 的精确 origin，即协议、主机名和端口。账号的登录路径必须匹配；忽略普通查询参数和路径末尾斜杠。保存了 hash 路由时还需匹配其路径，忽略 hash 中的查询参数。财资云单独限定到 `https://toc.icbc.com.cn/login.html` 的账号登录路由。

保留原财资云的固定主机权限和内容脚本。其他 HTTP/HTTPS 网站通过可选主机权限逐站点授权；声明可选权限并不自动获得所有网站的访问权。保存账号或点击“允许此网站”时，在用户操作中请求对应权限。

仅为已保存且获授权的网站注册持久化动态内容脚本。注册运行在隔离环境、顶层框架，浏览器重启后保留；弹窗初始化、保存、导入、删除等操作会同步注册。删除某站点的最后一条账号后移除对应动态注册；已授予的浏览器权限可在 Chrome 扩展详情中管理。

浏览器主机权限和脚本注册范围不等同最终填充范围。已授权网站上的内容脚本读取账号库后，根据保存地址选取匹配记录；缓存已知登录地址，减少无关路径上的重复读取。最终填写前仍检查 origin、路径、路由和当前输入框身份。

手动消息仅携带账号 ID，内容脚本自行读取对应记录，并验证发送扩展 ID。消息失败时，仅在尚无内容脚本接收端的情况下尝试注入；注入仍需相应的网站权限。

## 填写行为

自动填写只使用当前网站的默认账号；无默认账号时不选择第一条。手动填写可以替换整组已有内容。页面有其他账号或已有密码时，自动填写保持原内容，避免将默认密码与另一账号组合。

通用识别查找可见、可编辑的普通 `input`，结合 `autocomplete`、类型、标签、名称等识别账号、密码和可选企业编号。可搜索开放的 Shadow DOM；字段需位于同一表单或相同 DOM 根中。避开 OTP、验证码、注册及修改密码字段，多个密码候选不明确时不猜测。明确设置的 CSS 选择器优先用于定位。

异步填写分阶段检查用户编辑、配置版本、登录地址和字段节点。先写账号，再检查账号仍一致后写密码；用户新输入、节点替换、页面路由或设置变化会停止后续步骤。每个密码节点自动填写一次，表单重建后可重新识别。

不操作验证码、短信发送或登录按钮。多步骤登录、iframe、封闭 Shadow DOM、非普通输入框及其他专有安全控件不保证兼容。

## 财资云兼容依据

财资云页面为 Vue 2 / Element UI。企业编号、用户名的 placeholder 分别为“请输入企业编号”“请输入用户名”。密码输入框为 `.ComPasswordInput input[placeholder="请输入登录密码"]`，初始类型为 text。

组件在 input 事件中维护真实密码，再显示星号。写入时光标移到末尾；替换先清空并派发 input，等待页面更新后再填新密码。对该组件不紧接 input 同步派发 change，以维持掩码行为。普通网站派发 input 与 change。

切换登录方式会重建账号/密码节点，企业编号可能保留。账号和密码为空时，可将网站记住的企业编号替换为选定默认值。原始密码不会在插件存储时裁剪，但网站组件可能自行规范化输入。

## 备份与数据边界

本地账号没有独立主口令加密，不宣称生物识别、零知识保险箱或系统级凭据保护。插件不上传、不自动同步账号；填写后的网站字段由对应页面处理。

只有手动导出的备份使用口令加密：PBKDF2-SHA256 派生 AES-GCM 密钥，每次导出使用随机盐和 IV。备份口令至少 8 字符，不持久化。文件上限为 8 MB；导入在解密和完整校验通过后才修改本地数据。

导入按 origin、企业编号和账号组合合并，重复记录跳过且不覆盖密码；保留已有网站默认账号和当前总开关。新网站可采用备份中的默认账号，但导入不替用户授予网站权限。错误口令、损坏文件和超限数据返回失败，不部分写入。

密码生成使用浏览器加密随机数，可选择长度及是否包含符号，仅生成文本，不调用网站改密功能。

## 验证与交付

单元测试入口：`node --test tests/*.test.cjs`，覆盖数据迁移、默认账号、精确匹配、表单边界、编辑竞态、站点权限及备份校验。真实浏览器的兼容情况和实际执行结果单独记入 [validation.md](validation.md)，不以测试夹具代替真实网站验证。

交付原生 `extension` 文件夹、`credential-butler-v2.0.0.zip` 与中文 README。运行测试和制作安装包只使用虚构数据；安装包不包含用户凭据、浏览器配置或测试账号库。
