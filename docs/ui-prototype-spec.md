## 1. 产品定位与核心价值

- **定位**：专注多网站凭据本地隔离存储、单站点多租户账号管理及智能安全自动填充的 Chrome 扩展。
- **差异化优势**：
  1. **零远程依赖 / 零数据外传**：账号数据仅保存在当前浏览器 `chrome.storage.local`，提供带强口令加密（PBKDF2-SHA256 + AES-GCM-128）的离线备份/合并导入能力。
  2. **站点精确隔离**：基于严格精确的协议、域名、端口（Origin）以及路径和 Hash 路由进行权限控制与表单匹配，杜绝跨端口、跨站钓鱼冒领。
  3. **专有金融云深度适配**：内置针对工商银行财资云（Vue 2 + Element UI 自定义密码掩码组件）的专项兼容引擎。
  4. **单站多账号与默认机制**：各网站支持保存任意多组账号，且每个网站独立指派唯一的“默认账号”用于一键秒填。

## 4. 各模块详细功能与交互规范

### 4.1 模块一：顶栏导航区 (Header & Navigation)
- **品牌展示**：
  - 32px 皇家蓝渐变图标徽标，搭配白色钥匙/锁形轮廓。
  - 主标题动态映射：首页呈现“凭据管家”，编辑时显示“添加账号”/“编辑账号”，工具箱显示“工具”。
  - 副标题动态映射：首页显示当前 Tab 域名（如 `toc.icbc.com.cn`）或“多站点账号管理”；编辑页/工具页显示辅助功能指引。
- **导航操作**：
  - 返回按钮（`<`）：在二级视图（编辑页、工具页）时显示，替代品牌图标。支持键盘 `Esc` 返回或点击返回。带有未保存修改拦截校验。
  - 工具按钮（`工具`）：位于右上角，一键进入密码生成与备份管理视图。

### 4.2 模块二：当前站点上下文与权限申请 (Site Context & Security)
- **环境嗅探与权限判断**：
  - **已就绪 (`data-state="ready"`)**：翡翠绿指示灯，提示“当前页面可填写”。
  - **待授权 (`data-state="permission"`)**：琥珀色指示灯，显示“尚未允许此网站自动填写”，并浮现文本按钮 `允许此网站`。点击后立即通过 `chrome.permissions.request({ origins: [...] })` 调起浏览器原生权限弹窗。
  - **登录页未打开 (`data-state="unmatched"`)**：显示“请打开所选账号的登录页”，右侧提供 `打开登录页 ↗` 快捷链接，点击新建对应标签页。
  - **加载中 (`data-state="loading"`)**：微呼吸动画指示灯，提示“正在检查网站权限…”。

### 4.3 模块三：搜索与范围筛选器 (Search & Scope Controls)
- **分段范围控制 (Segmented Control)**：
  - 提供 `当前网站` 与 `全部账号` 两个互斥筛选状态。
  - 切换时平滑更新卡片流，当前若处于非可填写网址（如空白页或浏览器内置页面），`当前网站` 自动处于安全禁用态。
- **即时模糊搜索**：
  - 监听搜索框 `input` 事件，实时根据名称、登录页地址、企业编号、账号进行不区分大小写的匹配。
  - 无输入延迟，输入时避免卡片重放入场动画，保持输入流畅无闪烁。
  - 搜索结果联动账号总数角标（如显示 `1/4` 表示全部 4 条中命中 1 条）。

### 4.4 模块四：账号凭据卡片系统 (Account Card System)
- **卡片构成**：
  - **标题行**：账号自定义名称（无名称时回退显示账号名） + 默认账号专属冰蓝小徽标（`[默认]`）。
  - **站点行**：以等宽字体展示对应 Hostname（如 `mms.pinduoduo.com`）。
  - **凭据信息表格**：按双列网格紧凑呈现，支持企业编号（若有）和登录账号，长文本自动截断加省略号。
- **选中与高亮机制**：
  - 单击卡片整体触发选中，卡片应用聚焦纯白微凸阴影，左侧点亮 3px 纯正皇家蓝指示条。
  - 选中的账号与底部主操作按钮“填写当前页面”深度绑定。
- **快捷浮层菜单 (More Actions Popover)**：
  - 点击卡片右上角 `...` 调起原生语义化操作浮层，具备边界自动吸附定位。
  - **打开登录页**：调起 `chrome.tabs.create`。
  - **设为网站默认**：将当前卡片设为此 Origin 专属自动填充账号。
  - **复制企业编号 / 账号 / 密码**：在用户交互上下文中通过 Clipboard API 复制，成功后在底部状态栏予以反馈。
  - **删除账号**：触发二次危险确认模态。

### 4.5 模块五：底部操作与状态一体化坞 (Unified Bottom Dock)
- **自动填写总开关 (`#enabled`)**：
  - 统领所有网站的登录页自动触发填写流程；关闭后，打开任何登录页均不主动注入凭据。
  - 下方伴有辅助文案，提示“此网站默认：XXX”或“请选择默认账号以自动填写”。
- **填写当前页面主按钮 (`#fill-button`)**：
  - 当且仅当“当前页面 URL 与所选卡片精确匹配”且“已获得该域名宿主权限”时激活。
  - 视觉呈企业蓝立体渐变；未匹配或未授权时呈干净规整的禁用灰阶态，防止误触。
- **实时状态反馈栏 (`#app-status`)**：
  - 高度 28px~48px，采用无感知的底部贴合底纹。
  - 接收系统读写、跨进程通讯、剪贴板、安全校验等各类状态通知（绿色表示成功，红色表示异常，灰色为提示）。

### 4.6 模块六：账号录入与高级字段映射 (Account Editor)
- **字段规范与约束**：
  - **账号名称**：选填，最长 40 字符。
  - **登录页地址**：必填，需为合法 HTTP/HTTPS URL（规范化移除敏感凭据段，保留路径与 Hash）。
  - **企业编号 / 组织**：普通网站选填，最长 128 字符；**当登录地址属于工行财资云（`toc.icbc.com.cn`）时，系统自动转为必填且硬性限制最大 8 位字符**。
  - **账号 / 密码**：必填。密码字段提供一键明文切换眼睛按钮，保持密码原值存储，不丢失特殊字符。
- **高级字段匹配折叠区 (Selector Options)**：
  - 针对存在动态混淆 ID、双密码框或复杂企业登录系统的极端场景。
  - 支持分别指定企业编号、账号、密码的 `input` CSS 选择器（上限 256 字符），并内置冲突与非法选择器拦截。
- **防数据丢失保护**：
  - 离开未保存表单时，系统执行深度对比，若有修改则弹出对话框询问是否放弃。

### 4.7 模块七：安全工具箱 (Security Tools)
- **强密码生成器**：
  - 基于 `crypto.getRandomValues` 密码学安全随机算法，拒绝伪随机数。
  - 支持 16/20/24/32 位长度切换，可自由控制是否混入特殊符号。
  - 生成结果以只读等宽字体呈现，支持一键安全复制。
- **口令加密备份与合并导入**：
  - **导出**：要求输入不低于 8 位字符的强口令，采用 PBKDF2-SHA256（100,000 次哈希迭代）派生密钥，结合 AES-GCM 生成加密备份文件。口令不落盘、不保存。
  - **导入**：文件最大限制 8 MB，校验合法性后解密并以**增量去重**模式合并进本地库。绝不静默覆盖已有账号的密码，保护现有凭据安全。
- **危险清空区**：
  - 专为更换设备或交接电脑设计，支持两阶段防误触清除本地存储的一切凭证。
