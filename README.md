# 凭据管家 · 多站点自动填充 2.0

按网站保存多组账号，打开对应登录页时填写默认账号、密码和可选的企业编号。支持搜索、快捷复制、自定义字段、密码生成和加密备份。代码与安装包不包含预置账号或密码。

## 安装与首次使用

1. 使用 ZIP 时，先完整解压 `credential-butler-v2.0.0.zip`。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开**开发者模式**，点击**加载已解压的扩展程序**，选择内含 `manifest.json` 的 **extension** 文件夹。本机项目目录为 `D:\projects\插件\credential-butler\extension`。
3. 在 Chrome 工具栏的拼图菜单中固定**凭据管家 · 多站点自动填充**。点击图标即可在浏览器右侧滑出原生**常驻侧边栏**（边看网页边操作，无需担心弹窗失焦关闭），也可通过 Chrome 侧边栏按钮固定在右侧。
4. 打开需要填写的网站登录页，点击侧边栏的**添加账号**，填写登录页地址、账号和密码。网站需要企业编号时再填写；财资云的企业编号必填，最多 8 位。
5. 勾选**设为此网站的默认账号**，点击**保存账号**，按 Chrome 提示允许访问该网站。保持**自动填写默认账号**开启，刷新登录页即可使用。

请保留加载的文件夹；Chrome 直接从该目录运行扩展。验证码、短信获取和登录按钮由你操作。

## 从 1.0 升级

将新版 `extension` 内的文件覆盖到**原先加载的同一个文件夹**，在 `chrome://extensions` 点击本扩展的刷新按钮，再打开一次插件并刷新登录页。原来的财资云账号和自动填写开关会迁移到新版，原账号成为财资云的默认账号。

**不要先删除扩展，也不要换目录重新安装**，以免原扩展的本地数据丢失或无法沿用。升级后名称和界面会变为“凭据管家”。

## 日常使用

- **当前网站 / 全部账号**：切换列表范围；可按名称、网站、企业编号或账号搜索。
- **选择账号 → 填写当前页面**：手动填入选中的整组信息，可替换页面已有内容；临时选择不会改变默认账号。
- **账号右侧的“…”菜单**：编辑、设为默认、复制企业编号/账号/密码或删除。删除默认账号后，需要自行选择新的默认账号。
- **自动填写默认账号**：这是总开关，各网站分别设置一个默认账号；没有默认账号的网站不会自动选择第一条记录。
- **工具 → 密码生成**：选择长度和是否包含符号，生成后可复制；不会替你修改网站密码。
- **工具 → 清空账号**：确认后删除所有本地账号并关闭自动填写；已经填入网页的内容不会随之清除。

自动填写会等待输入框出现，并保留你新输入的内容。页面已有其他账号或密码时，点击**填写当前页面**可明确替换。

## 网站匹配与字段设置

每条账号保存一个具体的登录页地址。匹配时要求**协议、域名、端口和登录路径一致**；地址保存了 `#` 路由时，该路由也必须一致。查询参数和路径末尾的斜杠不影响匹配。例如 `https://portal.example/login` 不会填到其他域名、`http` 页面或 `/register` 页面。

新网站需要逐个授权。导入账号或撤销权限后，如果看到**允许此网站**，点击后按 Chrome 提示授权。浏览器的站点访问权限范围可能宽于登录路径，插件仍会按保存地址检查后填写。

通常无需设置字段。遇到无法识别的普通输入框，可在**编辑账号 → 高级：字段匹配**中填 CSS 选择器，例如 `input[name="username"]` 和 `input[type="password"]`。选择器应定位到对应的可见、可编辑输入框。

财资云使用专门的密码组件适配，请打开 [财资云账号登录页](https://toc.icbc.com.cn/login.html#/login) 并选择**账号登录**；密码显示为星号属于正常现象。

## 备份与恢复

进入**工具 → 加密备份**，输入至少 8 个字符的备份口令，再选择**导出备份**或**选择文件导入**。导入需要同一口令，文件上限为 **8 MB**。

导入只合并：同一网站（协议、域名和端口）、企业编号、账号均相同的记录会跳过，已有密码不会被覆盖。已有网站的默认账号及本机自动填写开关保持原设置；新网站仍需授权。恢复后可检查默认账号和总开关。

备份文件使用口令加密，口令不会保存到插件中，请自行保留。

## 本地数据与适用范围

账号保存在当前 Chrome 配置文件的 `chrome.storage.local`，插件不连接远程账号服务，不自动上传或同步账号。**本地保存的密码没有独立主口令加密；只有导出的备份文件经过口令加密。** 点击复制会把所选字段写入系统剪贴板；填入网页后的信息由该网站处理。

支持顶层页面上的普通 `input`，可查找开放的 Shadow DOM，并兼容财资云的指定密码组件。多步骤登录、iframe 内的表单、封闭 Shadow DOM 和其他专有安全控件不保证兼容。验证码、新密码或确认密码字段不作为自动填写目标，插件不提交登录。本项目与银行官方无隶属关系。

**没有自动填写时**，依次检查登录地址、网站权限、该网站的默认账号和总开关；更新扩展后刷新网页。若页面已经有输入，可使用手动填写；识别失败再检查高级字段设置。

## 开发

原生 JavaScript / Manifest V3，无需 npm 依赖或构建步骤，最低 Chrome 版本为 116（使用 Chrome 原生 Side Panel 与 Manifest V3）。源文件位于 `extension/`，当前设计见 [docs/design-v2.md](docs/design-v2.md)，验证记录见 [docs/validation.md](docs/validation.md)。

在项目根目录运行：

```powershell
node --test tests/*.test.cjs
```

修改后重新加载扩展并刷新登录页。测试使用虚构数据，不应把个人凭据写入源码、测试文件或 ZIP。
